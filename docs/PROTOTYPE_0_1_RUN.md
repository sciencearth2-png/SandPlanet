# SandPlanet Prototype 0.1 — 실행 방법

## 목표
현재 프로토타입은 최종 21일 게임의 전체 콘텐츠가 아니라 다음 플레이 감각을 빠르게 검증한다.

1. 3D 행성 허브에서 장소를 고른다.
2. 장소 화면에서 인카운터를 선택한다.
3. 2D 텍스트 인카운터에서 행동을 결정한다.
4. 시간과 의지가 소비되고 관계/정보/수송선 상태가 바뀐다.
5. 하루 종료 시 그날의 경향에 따라 개인/대인/기술 중 하나가 +1 된다.

프로토타입 콘텐츠는 DAY 3 종료 시 끝나지만 HUD는 최종 구조를 의식해 `DAY n / 21`로 표시한다.

## 처음 실행
1. `prototype-foundation` 브랜치 최신 내용을 pull한다.
2. Unity에서 프로젝트를 연다.
3. 컴파일이 끝날 때까지 기다린다.
4. 상단 메뉴에서 `Tools > SandPlanet > Generate Prototype 0.1`을 누른다.
5. 생성 완료 팝업을 확인한다.
6. `Assets/Scenes/SandPlanet_Prototype_01.unity`가 열린 상태에서 Play를 누른다.

생성 도구가 자동으로 만드는 것:
- 고정 카메라
- 모래 행성 그레이박스
- 수송선 / 묘지 / 거주지 / 오아시스 3D 랜드마크
- 클릭 가능한 장소 노드
- 샘플 UI와 게임 컨트롤러
- 그레이박스용 재질

## 현재 플레이 가능한 샘플
### 행성 허브
- 수송선에서 연기가 나는 글로벌 인카운터

### 오아시스
- 벤자민과 대화: 호감도 증가
- 오아시스 수질 조사: 기술 Soft Requirement 테스트
- 물 운반: 개인 경향 테스트

### 거주지
- 페이를 기술자 동료로 확보하는 샘플

### 수송선
- 방호 구역 점검
- 기술자 동료가 있어야 가능한 방호 패널 수리
- 방호 상태 0~3 단계 변화

### 묘지
- 벤자민 호감도와 수질 위험 정보를 요구하는 퀘스트 기반 설득 샘플

## 현재 임시 규칙
- 게임 기본 활동 시간: 08:00~22:00
- 최대 의지: 5
- 낮잠: 2시간 / 의지 +1
- 수면: 다음날 의지 +2
- 시작 능력치: 개인/대인/기술 총 6포인트
- 하루 종료: 가장 많이 사용한 경향 능력치 +1
- 동률일 경우 마지막으로 사용한 경향을 우선한다. **TEMP**
- 하루에 아무 경향 행동도 하지 않은 경우 개인 +1. **TEMP**
- Soft Requirement 부족 1당 의지 1로 보완. **TEMP**

위 TEMP 규칙은 플레이 테스트용이며 아직 정식 기획 확정이 아니다.

## 첫 플레이에서 체크할 것
- 장소를 클릭해 인카운터를 고르는 흐름이 자연스러운가?
- 시간 1~3시간의 가치가 체감되는가?
- 최대 의지 5 / 수면 +2 / 낮잠 2시간 +1이 실제 선택을 만드는가?
- 대인과 기술을 다르게 찍었을 때 같은 3일이 달라 보이는가?
- 호감도와 설득이 분리되어 있어도 이해하기 쉬운가?
- 기술자 동료 → 수송선 수리의 연결이 직관적인가?
- 3D 허브를 유지하면서 2D 장소/인카운터 UI로 넘어가는 방식이 게임에 맞는가?

## 아직 구현하지 않는 것
- 정식 21일 시나리오
- 1주차 공개/비공개 대형 분기
- 전체 스킬 트리
- 정식 캐릭터 퀘스트
- 완성형 수송선 수리 도면 UI
- 2주차 모래폭풍 성과 검증
- 3주차 수송선 내부 3D 허브
- 정식 아트/사운드/연출

이 항목들은 Prototype 0.1을 직접 플레이한 뒤 우선순위를 다시 정한다.
