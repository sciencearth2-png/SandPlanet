# SandPlanet Design State

> 현재까지 확정된 기획의 기준점. 세부 수치/공식 중 확정되지 않은 것은 TEMP/TBD로 취급한다.

## 1. Core fantasy
플레이어는 냉동 상태에서 깨어난 지질학자 제이가 되어 21일 동안 사람들과 관계를 맺고 모래 행성을 조사하며 수송선을 관리한다. 제한된 시간과 의지 안에서 누구와 무엇에 투자했는지가 Week 2의 대비, Week 3의 생존, 최종 출항/정착 결과로 이어진다.

핵심 성장 체감은 공격력이 아니라 **정보를 얻고, 선택지를 넓히고, 같은 문제를 더 빠르고 다양한 방식으로 해결하는 것**이다.

## 2. 21-day structure
### Week 1 — 발견
- D1~2: 벤자민이 제이를 깨운다. 함께 출발했고 제이를 기억하는 여섯 동료와 다시 만나 사고 이후의 시간과 현재 공동체를 파악한다.
- D3~6: 샘의 요청으로 오아시스의 장기 안정성을 조사한다. 지질학자 플레이를 `관찰 → 가설 → 확인`으로 경험한다.
- 조사 결론: **현재 오아시스와 현재 생활 방식만으로는 장기 거주를 보장할 수 없다.** 행성 자체가 절대 거주 불가라는 결론은 아니다.
- D7: 알아낸 사실을 모두에게 공개할지 제한적으로 공유할지 결정한다.

### Week 2 — 대비
- D8~14.
- 모래폭풍 접근이 본격화된다.
- 수송선의 생존/대피용 정비와 출항용 수리를 구분한다.
- 정착지, 오아시스, 묘지, 수송선 외부 등 무엇을 보존할지 선택한다.
- 선택지가 의도적으로 과포화되어 모든 것을 챙기기 어렵게 한다.
- D14까지 생존자들이 수송선으로 대피한다.

### Week 3 — 생존과 선택
- D15~21.
- 수송선 내부 4구역을 허브로 사용한다.
- 폭풍으로 시설/자원/사람 문제가 발생한다.
- 보리치와 제이의 관측으로 폭풍 종료를 판단한다.
- 주요 인물들과 미래에 대해 이야기한다.
- D21 이후 플레이 과정에 따라 출항/정착 방향의 결과를 확인한다.

## 3. Outcome direction
- 일부 출항: 비교적 쉬운 기본 클리어 방향.
- 전원 출항: 더 높은 준비 요구.
- 전원 거주: 정착 기반과 사람/장소에 대한 능동적 투자 요구.
- 수송선 핵심 기능 상실로 떠날 수 없는 실패성 거주 가능.
- 작은 최적/업적성 결과 가능성은 열어두되 최종 threshold는 TBD.

명시적인 `정착 점수 %` 같은 UI는 두지 않는다.

## 4. Time
- 기본 행동 가능 시간: 08:00~22:00.
- Morning 06:00~11:59 / Afternoon 12:00~16:59 / Evening 17:00~22:00.
- 시간대 판정은 Interaction 시작 시각 기준.
- 플레이어가 선택한 되돌릴 수 없는 세계/퀘스트 행동은 원칙적으로 최소 1시간 이상.
- 주요 행동은 3~6시간 이상도 충분히 사용한다.

## 5. Willpower
- 기본 최대 의지: 5.
- 수면: 현재 의지 +2, 최대치 초과 불가.
- 휴식: 3시간 → 의지 +1.
- Soft Requirement 부족분 보완, 심리적으로 강한 선택, 긴급 압축 등에 사용.
- Hard Requirement는 의지로 우회 불가.
- 정확한 Soft Requirement 환산식은 플레이 테스트 후 확정.

## 6. Growth
개인 / 대인 / 기술 각각 Lv + XP.
- 시작 시 Lv 합계 6 자유 배분.
- 각 Lv 상한 20.
- 6XP마다 즉시 Lv +1.
- 초과 XP 이월.

초기 밸런스 기준:
**12시간 ≈ 의지 4 ≈ 호감도 3 ≈ XP 12 ≈ 능력치 Lv +2**

모든 시간 소비가 자동으로 XP를 주는 것은 아니다. 관계, 시설, 정보 등 다른 보상이 주효용이면 XP는 0 또는 소량일 수 있다.

## 7. Relationship
- NPC별 호감도 0~5.
- 호감도와 설득은 별개.
- 관계는 신뢰/대화/정보를 열 수 있지만 캐릭터의 정체성/동기를 자동으로 뒤집지 않는다.
- 핵심 장면을 단순 반복 대화 파밍만으로 열지 않는다.

## 8. Content structure
### Interaction
플레이어가 캐릭터/사물/장소에서 직접 선택해 실행하는 행동.
- 비용: Time / Will
- 결과: XP / Affinity / State / Event / QuestAction 등
- `QuestRole=NONE/OFFER/PROGRESS`

### Event
플레이어가 선택하지 않아도 조건에 의해 자동/강제로 호출되는 스토리.
Event 결과도 State/QuestAction 등을 가질 수 있다.

### Quest
- Main / Character / Side.
- Character Quest는 주요 인물당 하나의 장기 반(半)메인 아크.
- Quest 상태는 조건만으로 자동 변경하지 않는다.
- 명시적 Interaction/Event 결과의 `QuestAction`으로만 변경.

### QuestStep vs State
- QuestStep: Quest 내부 진행 단계.
- State: Quest 종료 이후라도 다른 콘텐츠가 기억해야 하는 사실.

## 9. Week 1 character/narrative rules
핵심 인물: 제이, 샘, 지나, 페이, 벤자민, 보리치, 디야.

- 제이: 지질학자. 시작 능력치 배분은 과거 직업을 다시 쓰지 않고 현재 어떤 능력을 즉각 사용할 수 있는지를 나타낸다.
- 샘: 공동체 책임자. 사람과 결정의 부담.
- 지나: 자원/생활/안전 관리.
- 페이: 기술자. 창의적/협력적, 현재 출항 입장은 UNDECIDED 방향.
- 벤자민: 기술자. 아내와 아이를 사고로 잃었고 현재는 STAY 방향에서 시작. Character Quest `남겨진 이름들`.
- 보리치: 기상학자. 생존자 죄책감과 과로.
- 디야: 도시/공동체 연구자. 집/공동체 관점.

캐릭터의 `동기 / 공포 / 정체성`은 직접 행동 원리다. Big5는 말투/반응 참고값이다.

## 10. Preservation and departure
Week 2 수송선 작업은 두 종류로 구분한다.
- 생존/대피 유지보수: 모두에게 필요.
- 출항용 수리: 실제로 출항을 원하는 기술 인력이 필요.

현재 방향:
- 페이 또는 벤자민 중 최소 한 명이 LEAVE여야 적극적인 출항 수리 가능.
- 한 명이면 정상 효율, 둘이면 협업 효율, 둘 다 아니면 적극적 출항 수리 없음.

보존 대상 예:
- 물리적: 정착지 / 오아시스 / 수송선 / 자원.
- 정서적: 묘지 및 Character Quest의 일부 결과.
- 묘지 보존은 식량/물 같은 물리 자원을 생성하지 않는다.

## 11. Production direction
시스템 확장을 계속 늘리기보다 현재 데이터 기반을 유지하고 콘텐츠 밀도와 검증을 우선한다.
권장 순서:
1. Main anchor
2. Character big beat + 중간 반응
3. Side
4. ordinary/reactive Interaction
5. NPC schedule

## 12. UI philosophy
- UI는 서사를 대신하지 않고 현재 선택/진행을 이해시키는 보조 수단.
- Interaction 버튼은 실제 행동 문장이 우선.
- Quest type text를 반복 표시하기보다 색/marker를 활용.
- 로그는 상태 변화 확인용이며 `누구를 만났다` 같은 서사를 중복 서술하지 않는다.
- 장소 UI는 맵처럼 인물/사물을 배치하고 clipping/focus 연출을 사용한다.
